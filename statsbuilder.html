Season Stats Builder

Combine each game’s game-data.json into one season-stats.json for the Players page. Private tool for the committee. Do not link it on the website.

1. Choose files
Select this season’s game-data.json files (rename each so you can tell them apart). To add a game to existing totals, also select your current season-stats.json.

2. Match each team to its draft team number
3. Download

Upload the downloaded file to your GitHub repo, replacing the old one.
